# Reformed Thinking
Static app: ask a theological question; see Calvinist (Calvin's Institutes, Beveridge 1845), Lutheran (Book of Concord, Triglot 1921; public-domain Luther translations), KJV verses, and a comparison.
- Data: `data/topics.json` (generated by `kb/build.py`, which verifies every quote word-for-word against the source texts and fills KJV verse text).
- Engine: `app.js` — `providers` array; add an AI provider (e.g. a Netlify Function `/api/ask` returning the same topic shape) later.
- Deploy: any static host (GitHub Pages now; `netlify.toml` included for Netlify).
